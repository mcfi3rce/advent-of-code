# Advent of Code

All my Advent of Code solutions in one repo. Each year/language folder is its own project; run commands from inside that folder.

| Year | Language | Folder | Run tests |
|------|----------|--------|-----------|
| 2015 | Java 17 (Gradle) | [`2015/java`](2015/java) | `./gradlew test` |
| 2023 | Clojure (Leiningen) | [`2023/clojure`](2023/clojure) | `cd src && lein run` |
| 2024 | C# (.NET) | [`2024/csharp`](2024/csharp) | `dotnet test` |
| 2024 | TypeScript | [`2024/typescript`](2024/typescript) | `npm ci` (no test runner set up yet) |
| 2025 | Clojure (Leiningen) | [`2025/clojure`](2025/clojure) | `lein test` |

Puzzle inputs are gitignored. Put your own input files where each project expects them.
